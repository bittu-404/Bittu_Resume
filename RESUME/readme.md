## 🔧 Customization Guide

### Personal Information
Update the following sections in the HTML:

```html
<!-- Header Section -->
<h1 class="full-name">YOUR FULL NAME</h1>
<p class="nickname">YOUR NICKNAME</p>

<!-- Contact Information -->
<p>Your City, State</p>
<p>Your Phone Number</p>
<p>Your Email Address</p>
```

### Skills & Percentages
Modify skill levels in both CSS and HTML:

**CSS:**
```css
.html { width: 90%; } 
.css { width: 85%; }
/* Update percentages as needed */
```

**HTML:**
```html
<p class="skill-name">HTML <span class="skill-percent">90%</span></p>
```
